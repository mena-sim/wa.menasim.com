# menasim eSIM troubleshooting

## No internet / no data after install

1. Confirm you have arrived in the country/region the plan covers and the activation date has passed.
2. Settings: make sure the menasim line is turned ON and selected for Cellular/Mobile Data.
3. Turn ON Data Roaming for the menasim line (required for eSIM data plans; no extra charge on menasim).
4. Toggle Airplane mode on for 10 seconds, then off. Or restart the phone.
5. Check there is remaining data balance (ask support to check your balance).

## No signal / no network selected

1. Go to network selection and switch from Automatic to Manual, then pick a partner network.
2. If manual selection fails, switch back to Automatic and restart.
3. Make sure the phone is not locked to your home carrier (carrier-unlocked required).

## Set the APN (Android, if data still not working)

1. Settings > Connections > Mobile networks > Access Point Names.
2. Add a new APN using the APN name shown in your menasim confirmation (often the provider APN). Leave username/password blank unless specified.
3. Save and select the new APN, then toggle mobile data off and on.

iPhone usually configures the APN automatically; if not, contact support.

## QR code will not scan or "cannot add plan"

- Increase screen brightness on the device showing the QR, or print it.
- Ensure you are on Wi-Fi during installation.
- Use manual entry (SM-DP+ address + activation code) from your confirmation.
- If it says the code is already used, the eSIM may already be installed on another device - contact support for options.

## Slow speeds

- Speeds depend on the local partner network and congestion.
- Try switching network manually to another available operator.
- Check remaining balance; some plans reduce speed after a data cap.
