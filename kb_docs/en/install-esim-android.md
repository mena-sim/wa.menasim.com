# Install and activate your menasim eSIM on Android

Steps vary slightly by brand (Samsung, Google Pixel, etc.), but the flow is the same. Your phone must support eSIM and be carrier-unlocked. Connect to Wi-Fi before starting.

## Samsung Galaxy

1. Open the menasim confirmation with your QR code on another screen.
2. Go to Settings > Connections > SIM manager.
3. Tap Add eSIM (or Add mobile plan > Scan carrier QR code).
4. Scan the menasim QR code and tap Add / Confirm.

## Google Pixel

1. Go to Settings > Network & internet > SIMs.
2. Tap Add SIM, then tap Download a SIM instead? / Next.
3. Scan the menasim QR code and follow the prompts.

## Manual entry

If you cannot scan, choose "Enter it manually" / "Need help?" and type the SM-DP+ address and activation code from your menasim confirmation.

## After the eSIM is added

1. Go to Settings > Connections / Network > SIM manager and make sure the menasim eSIM is turned ON.
2. Set Mobile data to the menasim eSIM.
3. Turn ON Data Roaming for the menasim eSIM (Settings > Connections > Mobile networks > Data roaming, or in the SIM manager per-SIM settings). eSIM plans need roaming enabled; it does not add charges on a menasim plan.
4. If you have no internet after this, set the APN (see the troubleshooting guide).

## Important notes

- Install before travel, enable data + roaming when you arrive or on your activation date.
- A QR code can usually only be installed once - do not delete the eSIM to reinstall it.
- Restart the phone once after enabling roaming if the connection does not appear within a few minutes.
