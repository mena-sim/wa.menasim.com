# Install and activate your menasim eSIM on iPhone

Works on iPhone XS / XR and newer running iOS 12.1 or later. Make sure your iPhone is carrier-unlocked and connected to Wi-Fi before you start.

## Method 1: Scan the QR code (recommended)

1. Open the menasim confirmation (email or WhatsApp) that contains your eSIM QR code on another screen, or print it.
2. On the iPhone, go to Settings > Cellular (or Mobile Data / Mobile Service).
3. Tap Add eSIM (or Add Cellular Plan).
4. Tap Use QR Code, then point the camera at the QR code.
5. If asked, tap Continue and wait for the plan to be added.

## Method 2: Enter details manually

If you cannot scan the QR, on the Add eSIM screen choose Enter Details Manually and type the SM-DP+ address and activation code from your menasim confirmation.

## After the eSIM is added

1. Label the plan (for example "menasim Travel") so you can tell it apart from your home SIM.
2. Choose which line is your Default Line and which is used for Cellular Data. Set menasim as the data line while travelling.
3. Turn on the line: Settings > Cellular > select the menasim plan > enable Turn On This Line.
4. Turn on Data Roaming for the menasim line: Settings > Cellular > menasim plan > Data Roaming = ON. eSIM data plans require roaming to be enabled; this does NOT incur extra charges on a menasim plan.
5. Set Cellular Data to the menasim line.

## Important notes

- Install the eSIM before you travel, but only enable the line and roaming once you arrive at your destination (or on the activation date shown on your order).
- Do not delete the eSIM to "reinstall" it. Most eSIM QR codes can only be installed once. If you delete it you may need a replacement.
- Keep your home line for calls/SMS and use the menasim line for data if you want to avoid home-network roaming fees.
